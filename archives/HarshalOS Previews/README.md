review art, not browser-delivered assets. The runtime orb animation is built
from the sequenced frames under [`assets/orb/`](../../assets/orb/),
[`assets/outer_flame/`](../../assets/outer_flame/), and
[`assets/flame/`](../../assets/flame/).

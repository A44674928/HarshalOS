# Imported author material

Incoming author bundles that have not (yet) been merged into the
[`business plan/`](../../business%20plan/) tree or other maintained paths.
Nothing in this directory is part of the browser asset bundle.

| Folder | Contents |
|---|---|
| [`New Models/`](New%20Models/) | Newer author-named model skeletons under the A-Frame / Container / Valve taxonomies (populated primarily with `.gitkeep` placeholder slots and pipe-named `.txt` token files) |
| [`Old Backup/`](Old%20Backup/) | Superseded Fractal Flames project directories (`Flame Directory`, `Flame Directory 2`, older `.flame` / `.bak` working files, and "EmptyFolder Set" placeholder directories) |

The new-model slot trees mirror the naming conventions used in
`business plan/StarPortal/Access/Alphabet/TOTOPOTUS/…` and are retained as
author material; the slot-preservation policy in
[`docs/architecture/PLUGIN-ARCHITECTURE.md`](../../docs/architecture/PLUGIN-ARCHITECTURE.md)
applies to all reserved paths, whether they currently live under
`business plan/` or here.

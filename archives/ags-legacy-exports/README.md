# AGS legacy exports

Older exported editions of Harshal's Systems from when the framework was still
branded "AGS" / "AGS++". These are retained for provenance only; the
authoritative manual is under [`publications/harshal-systems/`](../../publications/harshal-systems/)
and the modular reference library is under [`docs/harshal-systems/`](../../docs/harshal-systems/).

| File | Format | Notes |
|---|---|---|
| `AGS.epub` | EPUB (Apple Books) | Early single-chapter eBook export dated January 2026 |
| `AGS++.pages` | Apple Pages | Earlier Pages-draft export of the full work |

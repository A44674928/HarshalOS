HarshalOS

Architectures for Accountable Human D'Ash Machine Intelligence

HarshalOS is an accountability-gated operating system: a working demonstration of AGS++, where the system must establish legitimacy before it can act, and its default state is refusal.

What it demonstrates

  • The legitimacy gate — every action must clear L(t) = H(t) × f(A(t), R(t), S(t)) against an absolute threshold τ. Below threshold, the system refuses; no objective can override a stopping condition.
  • The Human Key — authority decays with time (Δt / δ). A verified human must re-attest liveness, or the system collapses to a mathematically void, refusal-bound state.
  • The Symbolic Firewall — narrative and mythic expressions are strictly non-executable: symbolism never becomes capability.
  • Ground-0 phase detection — institutions are classified by observed behavior rather than declared intent, with every state change witnessed in a SHA-256 hash-chained duty ledger.

Who built it

Harshal Priyavadan Patel, independent AI governance researcher and author of the AGS++ framework family.

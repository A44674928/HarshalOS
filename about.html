HarshalOS

Architectures for Accountable Human D'Ash Machine Intelligence

HarshalOS is a browser-based demonstration of accountability-gated AI governance. It exercises a local model of pre-action gates and refusal; it is not a production security boundary and does not grant production authority.

What it demonstrates

  • The legitimacy gate — every action must clear L(t) = H(t) × f(A(t), R(t), S(t)) against an absolute threshold τ. Below threshold, the system refuses; no objective can override a stopping condition.
  • Human Key demo — the public browser phrase starts an asynchronous local lifecycle: while the HMAC is pending, H(t) stays 0 and actions are refused; only a successful, current, still-fresh completion activates the demo marker. Failure, revocation, expiry, and superseded completions fail closed. This does not verify identity, liveness, consent, consciousness, or biological coupling; production authentication and authorization remain unavailable.
  • The Symbolic Firewall — narrative and mythic expressions are strictly non-executable: symbolism never becomes capability.
  • Ground-0 phase model — the workspace demonstrates classification by observed behavior. Its SHA-256 hash-chained log is held in the browser and is not an independent witness or tamper-proof record.

Publishing Hierarchy & Canonical Minimum Model

  • Canonical Minimum Model — Identity → Representation → Authorization → Continuity → Accountability → Refusal. Computational components are never moral or legal agents (INV-AGENCY-001); execution may be delegated, but legitimacy never migrates away from the human key (INV-LEGIT-001).
  • Book I — Harshal's Systems (Parts I–XXVII) — The canonical technical, constitutional, and safety reference library, led by the flagship research paper Accountability in Keyed Human–Machine Hybrid Systems (Part XIX).
  • Book II — Preview — The Grand River Foundation — The standalone fictional companion novel set in ~2100 CE around the 4,000-foot retrofitted Colorado River dam, the 500-Coin Western Colonnade, and the 119-NAB Ombudsman's Council.

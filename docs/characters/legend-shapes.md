# Characters Chart Legend — Visual Shape Mapping

Purpose: distinguish market interaction types by unique polygon shape (not just color). Color stays as existing palette.

Shape sequence (3 through 7 sides):
- Triangle (3 sides) — Selloff
- Quadrilateral / Square (4 sides) — Rally
- Pentagon (5 sides) — Correction
- Hexagon (6 sides) — Accumulation
- Heptagon (7 sides) — Distribution

Use: Each interaction type in the Characters market-beat chart displays its assigned polygon marker. Shape is independent of Disc (stocks/fx/crypto/commodities) and of color tints. If additional types are needed beyond 7, extend to octagon (8) / nonagon (9) / decagon (10) in order, but core set stops at heptagon per request.

# v2.2 print fonts (vendored for reproducible builds)

- **Tinos** Regular/Italic/Bold/BoldItalic — metric-compatible with Times New
  Roman; body and heading face. Apache License 2.0, (c) The Tinos Project
  Authors. Sourced via `@expo-google-fonts/tinos` (npm).
- **Cousine** Regular/Italic/Bold/BoldItalic — metric-compatible with Courier
  New; code/diagram face. SIL Open Font License 1.1, (c) The Cousine Project
  Authors (see `OFL-1.1-Cousine.txt`). Sourced via
  `@expo-google-fonts/cousine` (npm).
- **DejaVu** Serif/Sans/Mono (Regular/Bold) — fallback face for symbols
  outside Tinos/Cousine coverage (logic/math glyphs). DejaVu Fonts License
  (Bitstream Vera-derived permissive terms plus public-domain additions);
  see https://dejavu-fonts.github.io/.

All three families permit embedding in PDFs and redistribution. The KDP
interior PDF embeds subset instances of every used face.

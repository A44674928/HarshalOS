## 📝 NOTES

### UTS Precision
- All timestamps use **6 decimal places** for sub-day accuracy
- This provides **~11.57 microsecond precision** (1 UD / 10⁶ ≈ 11.57 μs)
- Sufficient for most documentation purposes

### UTS vs Earth Time
- **UD** (Universal Date) = years since Big Bang in Universal Days
- **UY** (Universal Year) = duration unit (365.25 UD)
- Earth time remains the primary human-readable format
- UTS provides the **universal standard** for system operations

### Timestamp Format
The format `UTS: YYYY-MM-DD HH:MM:SS UTC (UD XXXXXXXXXXXX.XXXXXX)` provides:
- Human-readable Earth time
- Machine-readable UTS time
- Both formats for maximum compatibility

## Build / interpretation rule

Use the package in the hierarchy **“The architecture (Book I) is the library. The novel (Book II) is the work in active production.”** For Book II continuity, 2046 is the target first operational module, 2098 is an interim milestone within an expansion phase, and construction is not declared finally complete. Mistveil targets approximately 80 million residents by 2100; the earlier 40-million Book II figure is retained only as an illustrative regional service-population metric, not a city census. Its overlap with city residents is unspecified, so the two counts must not be added.
